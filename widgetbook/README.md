# BeneathSOS UI catalogue

The Widgetbook catalogue of `beneathsos_ui`: every component in light and dark, 100–200 % text, phone
sizes. Live at <https://berkant35.github.io/beneathsos_ui/>, built and published by
`.github/workflows/catalogue.yml` from `main` (`--no-web-resources-cdn --base-href /beneathsos_ui/`).

```
fvm flutter run -d chrome
fvm flutter test
```
